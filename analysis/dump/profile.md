### 8.4 Recommended `COPY`

```sql
-- stage every column as text, then cast
COPY weld_dump_raw FROM '/path/Weld Dump.txt'
  WITH (FORMAT csv, DELIMITER ';', HEADER true,
        QUOTE E'\b', ESCAPE E'\b',   -- no quoting in the source
        ENCODING 'UTF8', NULL '');
```
Caveats that make plain `COPY` unsafe as-is:
- the header row has 226 names vs 223 data fields -> declare **223** staging columns and load with `HEADER true` (the surplus names are simply ignored) **or** strip the header and use `HEADER false`;
- 17 records contain an embedded CRLF and 1,236 contain a bare LF inside a field; `COPY ... FORMAT csv` without quoting will break on those. Pre-clean with a script that re-joins lines until the `;` count reaches 222 (this profiler does exactly that), or accept ~17 bad rows.
- null tokens beyond `''` (see §8.2) must be mapped in the cast step, not by `COPY` (which accepts only one NULL string).
